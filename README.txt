SKYCAST WEATHER - ANDROID STARTER PROJECT

What is included:
- City search
- Current temperature and feels-like temperature
- Humidity and wind
- Rain probability
- Sunrise and sunset
- 5-day forecast
- Celsius/Fahrenheit switch
- Optional current-location button
- Installable PWA support

STEP 1 - Test it:
You need to host the files on an HTTPS website for location and install features to work reliably.
Upload index.html, manifest.webmanifest and service-worker.js to a GitHub repository.
In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
Wait for the Pages URL, then open it in Chrome on Android.

STEP 2 - Install on Android:
Open your HTTPS GitHub Pages URL in Chrome.
Tap the three-dot menu > Install app (or Add to Home screen).
Confirm. Skycast will appear on your home screen.

STEP 3 - Use:
Search a city such as Nellore, or tap Use my location and allow location permission.
Tap °C / °F to change units.

Weather provider:
Open-Meteo public forecast and geocoding APIs. No API key is required for this starter.
An internet connection is needed for fresh weather data.

NOTE:
This is an installable web app (PWA), not yet a Play Store APK. A native Android APK can be packaged later.
